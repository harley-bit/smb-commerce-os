# Build Calendar

Sequential, not date-locked. Under token-maxing execution, real elapsed time between cards varies with usage-limit resets, not the calendar — the **Day ID is the source of truth for sequence**, not a date. Each row links to its card (the prompt/plan for that unit of work) and its log (written once that card is actually run).

**Do not skip a Day ID.** If a card is split or reordered, record that as a note in the card file and in the weekly review — never renumber.
