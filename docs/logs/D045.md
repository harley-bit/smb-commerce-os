## What happened

Added `packages/domain/src/utils/interval.ts`: an `Interval` type (`{ start, end }`, both UTC ISO-8601 strings per the existing `time.ts` convention) representing a half-open `[start, end)` span, a `makeInterval(start, end)` constructor that validates both endpoints are UTC-ISO (`isUtcIso`) and that `start` is strictly before `end` (rejecting zero-length and inverted ranges), and `intervalsOverlap(a, b)`, a pure predicate implementing the standard half-open overlap test (`a.start < b.end && b.start < a.end`).
