## Security check answer

"Prices fetched server-side, never cached stale" — answered by construction. `fetchProductDetail` passes `cache: "no-store"` on every call (asserted directly in `fetchProductDetail.test.ts`), `ProductDetailScreen` re-fetches on every mount via `useEffect`, and neither module persists a price anywhere (no AsyncStorage/SecureStore/module-level cache) — there is no code path that could read a price the server didn't just return in that exact response.
